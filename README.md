This project is a Kahoot Rip Off but Ciphers

Step 1:
Users should download this file off my GitHub: nikolisr to play multiplayer in class

Step 2:
Simply change the parameters in server/serverConstants.py MYIPADDRESS to add the IP address of your computer
Ensure that the port is open to call back too (In this case it's 5555)

Step 3:
run python server/server.py
in terminal to run the server on the IP:Port you want

Step 4:
run python client/client.py
in terminal. You will be prompted to the IP ADDRESS to join.

Step 5:
Enjoy something that was fun to make!
